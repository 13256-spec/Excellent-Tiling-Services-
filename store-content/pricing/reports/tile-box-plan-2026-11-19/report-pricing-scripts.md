## 2. How each script treats m2-units and what must change

### `tile_m2_units_2026_11.py` (the one-off conversion script)
- `:5-11 plan()`: price per m² floored to whole dollar (bumped up if that breaks 25%), `unit = new/100`, trade unit = `unit x (100-band)/100` with `ROUND_CEILING`.
- `:38-61 batches()`: one `productVariantsBulkUpdate` per product + `tagsAdd "m2-units"`, variant input at `:49-50`: `price: unit`, `showUnitPrice:true`, `unitPriceMeasurement:{quantityValue:0.01, quantityUnit:M2, referenceValue:1, referenceUnit:M2}`, `inventoryItem:{cost: cost/100 (4 dp), measurement:{weight: kg_per_m2/100}}`. Requests chunked under 15,500 chars (`:55`).
- **Per-box**: this script is superseded; a new `tile_box_units_2026_11.py` (same shape) needs a per-variant `m2_per_box` input (CSV keyed by SKU) and must write: `price = (price_per_m2 * m2_per_box)` to the cent, `quantityValue: <m2_per_box>` (e.g. 1.44), `quantityUnit:M2, referenceValue:1, referenceUnit:M2`, `inventoryItem.cost = cost_per_m2 * m2_per_box` (Shopify keeps 2 dp — per-box rounding error ≤ $0.005/box, which fixes today's "admin margins off by up to $0.50/m²" problem at README line 323), `weight = kg_per_m2 * m2_per_box` (today's stored weight is kg/m² ÷ 100, so new weight = stored x 100 x m2_per_box), and `tagsRemove "m2-units"` (+ a new tag such as `box-units` if the theme needs a switch). The whole-dollar-per-m² constraint at `:6` no longer matters (box price can be any cents), but keeping it means box prices stay clean and nothing changes for customers. Inventory on hand is currently in 0.01 m² units and must be divided by (100 x m2_per_box) — outside the pricing scripts but it breaks if forgotten.

### Margin arithmetic
- Margin = (price - cost)/price is unchanged by multiplying both by m2_per_box, so every variant that clears the floors per m² clears them per box. Only trade rounding moves, by ≤ 0.5c per box.
- The one new risk: if the box price is rounded (e.g. down to 10c under the tile rounding rule) the displayed $/m² (= Shopify price / quantityValue) drifts by a few cents from the owner's whole-dollar figure. Recommend: box price = per-m² price x m2_per_box exactly (to the cent, half up), no extra rounding.

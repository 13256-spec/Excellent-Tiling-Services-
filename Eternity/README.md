# Eternity

Everything Eternity sends us: price lists, catalogues, spec sheets, emails, terms and account details.

Drop files straight into this folder. Use a clear name with the date, for example
`eternity-price-list-2026-11-05.pdf`.

Eternity is our tile supplier (and DSA bathroomware via Eternity/DSA). Pricing rules for their lines are in
`store-content/pricing/PRICING-PLAYBOOK.md`. Nothing here changes a price in Shopify on its own; any price
change still needs the owner's approval first.
